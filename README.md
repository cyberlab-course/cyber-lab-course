# 🛡️ Cyber Lab Course

> Free penetration testing & red team course — from complete beginner to OSCP level.  
> **1200+ structured lessons** covering the full attacker lifecycle.

---

## 📖 About

This is a complete, structured cybersecurity course built from the ground up. It follows the real attacker methodology: **reconnaissance → scanning → exploitation → privilege escalation → post-exploitation**, plus defense, reporting, and career guidance.

Each lesson is beginner-friendly, explains the *why* behind every command, and includes hands-on practice on **Kali Linux, TryHackMe, Hack The Box, and DVWA**.
