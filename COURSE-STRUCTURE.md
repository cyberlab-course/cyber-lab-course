## 📌 Lesson Format Rules

Each lesson follows this structure:
`Why → Explanation → Remember → Key Terms → Commands → Command Breakdown → Practice (THM/HTB hints) → Defense → Homework → Beginner Mistakes → Summary → Walkthrough`

- Commands formatted uniformly with code blocks
- THM/HTB practice added only when a relevant room/machine exists — hints only, no solutions
- Two versions maintained: 🇷🇺 Russian (Telegram) + 🇬🇧 English (GitHub/Telegram EN)
- File naming: `Block-XX-Name/Lesson-YY.md`
